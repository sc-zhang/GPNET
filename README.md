## Introduction

This software is used for creating network for genotype and phenotype analysis.

## Dependencies

Software:

- Python 3.7+
- rust

Python modules:

- numpy
- xgboost
- scikit-learn
- pathos
- networkx

## Installation

```bash
cd /path/to/install
git clone https://github.com/sc-zhang/GPNET.git
cd GPNET
chmod +x gpnet.py

# build rust lib
cd fast_ridge
cargo build --release
cp target/release/libfast_ridge.so ../gpnet/lib/fast_ridge.so
cd ..

# Optional
echo 'export PATH=/path/to/install/GPNET:$PATH' >> ~/.bash_profile
source ~/.bash_profile
```

## Usage

- Main program

```bash
usage: gpnet.py [-h] {simulator,predictor,selector,visualizer} ...

options:
  -h, --help            show this help message and exit

sub commands:
  {simulator,predictor,selector,visualizer}
    simulator           Simulate genotypes and phenotype of a population
    predictor           Predict best genotype with population
    selector            Get most effective genes from network generated by CWNET
    visualizer          Visualize network generated by CWNET
```

- simulator is used for simulating data for testing our methods.

```bash
usage: gpnet.py simulator [-h] -o OUTDIR [-r ROUND] [-s SITES] [-a AVG_TYPES] [-n NOISE] [-c SAMPLES] [-b] [-p PARENT] [--seed SEED] [-t THREAD]

options:
  -h, --help            show this help message and exit
  -o, --outdir OUTDIR   Output directory
  -r, --round ROUND     Simulate round, default=1000
  -s, --sites SITES     Simulate variant site count, default=100
  -a, --avg_types AVG_TYPES
                        Average of variant types, default=5
  -n, --noise NOISE     Noise ratio of sites, these sites have lower genomic valuethan others , default=0.0 and less than 1
  -c, --samples SAMPLES
                        Simulate sample count, default=100
  -b, --hybrid          Means simulate a hybrid population, if this parameter is setting
  -p, --parent PARENT   Parent counts for simulating hybrid population, only effect when hybrid is setting, default=10
  --seed SEED           Random seed for simulating data, default=None
  -t, --thread THREAD   Threads, default=10
```

- predictor is used for predicting best genotypes with phenotypes from population.

```bash
usage: gpnet.py predictor [-h] -i INPUT [-w WEIGHT] -o OUTPUT [--single] [-m {CWNET,CWNET_FR,MLR}] [-l] [--normalization] [--store_iter] [--top_edges TOP_EDGES] [--min_edge_count MIN_EDGE_COUNT] [--step_size STEP_SIZE] [--optim {SA,GA}] [--iter ITER] [--alpha ALPHA] [--n_gen N_GEN] [--pop_size POP_SIZE]
                          [--cross_rate CROSS_RATE] [--mutation_rate MUTATION_RATE] [--seed SEED] [-t THREAD]

options:
  -h, --help            show this help message and exit
  -i, --input INPUT     Input data file or list file
  -w, --weight WEIGHT   Weight file or list file, required if data is generated by gpnet.py simulator
  -o, --output OUTPUT   Output file or directory
  --single              Input file is a single sample file
  -m, --method {CWNET,CWNET_FR,MLR}
                        Predict method, can be: CWNET, CWNET_FR, MLR, default=CWNET
  -l, --lower           Means lower phenotype is better, if this parameter is setting
  --normalization       Normalization weight of nodes and edges with min-max, if this parameter is setting
  --store_iter          Store iteration file if is setting
  --top_edges TOP_EDGES
                        Maximum number of edges to attempt to search (Max Edges)
  --min_edge_count MIN_EDGE_COUNT
                        Minimum frequency of edge appearance
  --step_size STEP_SIZE
                        Step size when searching for edges (default is 50)
  --optim {SA,GA}       Optimize method for predicting best one, default=SA
  --iter ITER           Number of iterations for SA algorithm, default=100
  --alpha ALPHA         Alpha value for SA algorithm, default=0.99
  --n_gen N_GEN         Number of generations for GA algorithm, default=1000
  --pop_size POP_SIZE   Number of individuals in population for GA algorithm, default=200
  --cross_rate CROSS_RATE
                        Cross rate of crossover for GA algorithm, default=0.8
  --mutation_rate MUTATION_RATE
                        Mutation rate for GA algorithm, default=0.05
  --seed SEED           Random seed for predictor, default=None
  -t, --thread THREAD   Threads, default=10, if input single file, auto set to 1
```

**Notice**:

1. Input data file for real data can be got in 08.VariantMatrix folder which is generated
   by [MATE](https://github.com/sc-zhang/MATE) we developed.
2. optimize method could be one of SA (Simulated Annealing) and GA (Genetic Algorithm), the iter/alpha parameters only
   worked with SA and n_gen/pop_size/cross_rate/mutation_rate parameters only worked with GA.
3. List file is a text file, one line contain one data/weight file path.
4. Weight file or list file contain path of weight files is not need with real data.
5. If *--single* is setting, that means the file provided with *--input* and *--weight* parameter is not a list file,
   but a data/weight file.


- selector is used for selecting most effective genes from network generated by CWNET

```bash
usage: gpnet.py selector [-h] -i INPUT [-m MODEL] -o OUTPUT [-n COUNT] [-l] [--iter ITER] [--alpha ALPHA] [--seed SEED]

options:
  -h, --help           show this help message and exit
  -i, --input INPUT    Input result file of CWNET/CWNET_FR
  -m, --model MODEL    Model file generated by CWNET_FR
  -o, --output OUTPUT  Output list file of best genes
  -n, --count COUNT    Gene counts for selecting, default=5
  -l, --lower          Means lower phenotype is better, if this parameter is setting
  --iter ITER          Number of iterations for SA algorithm, default=100
  --alpha ALPHA        Alpha value for SA algorithm, default=0.01
  --seed SEED          Random seed for selector, default=None
```

- visualizer is used for drawing network generated by CWNET

```bash
usage: gpnet.py visualizer [-h] -i INPUT -o OUTPUT [--predicted_only] [--highlight_color HIGHLIGHT_COLOR] [--node_cmap NODE_CMAP] [--edge_cmap EDGE_CMAP] [--node_ratio NODE_RATIO] [--edge_ratio EDGE_RATIO] [--lower] [--label_top_nodes LABEL_TOP_NODES] [--label_top_edges LABEL_TOP_EDGES]
                           [--edge_alpha_min EDGE_ALPHA_MIN] [--draw_top_nodes DRAW_TOP_NODES] [--draw_top_edges DRAW_TOP_EDGES]

options:
  -h, --help            show this help message and exit
  -i, --input INPUT     Input result file of CWNET
  -o, --output OUTPUT   Output picture file of network
  --predicted_only      Nodes and edges only contained in predicted sample would be drawn, default=False
  --highlight_color HIGHLIGHT_COLOR
                        Color for select nodes and edges, default="orange"
  --node_cmap NODE_CMAP
                        Colormap for nodes, default="Greens"
  --edge_cmap EDGE_CMAP
                        Colormap for edges, default="Greens"
  --node_ratio NODE_RATIO
                        Ratio of node size, higher means smaller node size, default=3.0
  --edge_ratio EDGE_RATIO
                        Ratio of edge width, higher means thinner edge width, default=20.0
  --lower               Means lower phenotype is better, if this parameter is setting
  --label_top_nodes LABEL_TOP_NODES
                        Number and legend top-N nodes by weight value, (default=-1 not set)
  --label_top_edges LABEL_TOP_EDGES
                        Number and legend top-N edges by weight value, (default=-1 not set)
  --edge_alpha_min EDGE_ALPHA_MIN
                        Minimum alpha for weakest edges (default=0.06)
  --draw_top_nodes DRAW_TOP_NODES
                        If set, only draw the top-N nodes (by weight) and extra nodes from top-N edges, (default=-1 draw all)
  --draw_top_edges DRAW_TOP_EDGES
                        If set, only draw the top-N edges (by weight), if not set and --draw_top_nodes set, set to the same value of draw_top_nodes, (default=-1 draw all)
```
